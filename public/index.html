🎙️ Voice Commands Cheat Sheet

What You Say Action Performed
"Next" or "Next Field" Advances to the next form field
"Back" or "Previous" Returns to previous form field
"Add Row" or "Next Person" Saves current row to memory, resets form, and focuses First Name
"Clear" or "Reset" Clears all inputs in current form
"Generate Excel" or "Final Submit" Compiles all staged rows and saves records.xlsx
"First Name [name]" Jumps directly to First Name and fills it
"Last Name [name]" Jumps directly to Last Name and fills it
"Age [number]" Jumps to Age and parses number (e.g. "twenty five" → 25)
"Sex [Male / Female / Other]" Jumps to Sex and normalizes selection
"Phone [digits]" Jumps to Phone No and extracts phone digits
"Address [text]" Jumps to Address and fills location text
Nikshay IDs Mode Commands
"[Any Numbers]" e.g. "8 4 9 2 0 1 5" Parses digits and adds Nikshay ID to the list immediately
"Delete Last" or "Remove" Removes the last added Nikshay ID from the list
"Clear" or "Clear All" Clears current input or staged list
"Generate Excel" Exports queued IDs to nikshay_records.xlsx
